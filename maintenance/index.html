06 / FAQ

Asked, answered.

How am I billed?

Per minute of compute used. One credit always equals one US dollar, so the math is direct.

What happens when my credits run out?

Workloads stop automatically when your balance reaches $0. Usage can never run past available credit.

How do I get an API key?

Request one from the dashboard. One login works across Aorila, Aorila Labs, and Atraly.

What hardware is available?

GPU availability depends on hosts listing hardware. The dashboard shows what is currently listed.

Are there long-term commitments?

No. There are no contracts and no reserved tiers to manage — launch, run, and stop whenever you like.
