Get a consumer key

  1. Email hello@aorila.com and ask for an Atraly v1 key.
  2. You receive a bearer token scoped to the consumer API.
  3. Send Authorization: Bearer <key> on every request.

Chat completions

Base URL: https://api.aorila.com/v1

curl https://api.aorila.com/v1/chat/completions \
  -H "Authorization: Bearer $AORILA_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "atraly-v1",
    "messages": [
      {"role": "user", "content": "What does Aorila build?"}
    ]
  }'

OpenAI-compatible messages payload. Stream with "stream": true when you need tokens as they land.
