Chat completions

Base URL: https://api.aorila.com/v1

curl https://api.aorila.com/v1/chat/completions \
  -H "Authorization: Bearer $AORILA_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "atraly-v1",
    "messages": [
      {"role": "user", "content": "What does Aorila build?"}
    ]
  }'
