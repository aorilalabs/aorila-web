How to get API keys

Access is quoted. Dedicated is 1.5× current RunPod list. Early access — may change.

  1. Send the contact form, or write sales@aorilalabs.com as a backup.
  2. We issue a Labs bearer token. Consumer keys from aorila.com will not work here.

Chat completions

Base URL: https://api.aorilalabs.com/v1

curl https://api.aorilalabs.com/v1/chat/completions \
  -H "Authorization: Bearer $AORILA_LABS_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "atraly-v1.5",
    "messages": [
      {"role": "user", "content": "Summarize this contract risk."}
    ]
  }'

Same chat-completions shape as the consumer API. Stream with "stream": true.
